# Employee Payroll Management System

A Node.js web application for managing employee payroll data. Built with Express.js and EJS templating.

## Features
- View employee list
- Add new employees
- Edit existing employee details
- Store data in JSON format
- Responsive web interface

## Installation
1. Clone the repository.
2. Run `npm install` to install dependencies.
3. Start the server with `npm start` or `node server.js`.
4. Open `http://localhost:3000` in your browser.

## Usage
- Navigate to the home page to view employees.
- Use "Add Employee" to create new entries.
- Click "Edit" on an employee to update details.

## Project Structure
- `server.js`: Main server file
- `modules/fileHandler.js`: Handles JSON data operations
- `views/`: EJS templates for UI
- `public/`: Static assets (CSS)
- `employees.json`: Employee data storage

## Technologies
- Node.js
- Express.js
- EJS
- JSON for data storage
